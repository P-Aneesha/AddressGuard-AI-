# AddressGuard AI — 1,000-Case Stress Test

## Scope

The project contains 34 labelled seed cases and a deterministic 1,000-case synthetic stress dataset derived from them. The dataset exercises valid, typo, correctable, missing-field, mismatch, suspicious, random-text and formatting scenarios.

This is a **stress test**, not 1,000 independent real-world addresses.

## Current measured result

The full deterministic pipeline was executed locally against all 1,000 cases with live external services disabled.

- Cases: **1,000**
- Accuracy: **100.00%**
- Macro Precision: **100.00%**
- Macro Recall: **100.00%**
- Macro F1: **100.00%**
- Correction exact-case match: **100.00%**
- Correction field precision: **100.00%**
- Correction field recall: **100.00%**
- Average pipeline time: **11.617 ms/case**
- Failures: **0**

Results are generated by `evaluation/run_1000_stress.py` from actual pipeline outputs. Metrics are not hardcoded.

## AI-enabled evaluation

To measure the Groq contextual AI layer on the same cases, configure the API key and run:

```powershell
python evaluation\run_1000_stress.py --ai
```

The AI-enabled result should be treated as a separate experiment because model responses and network latency can vary.

## Limitation

The 1,000 cases are synthetic variants of 34 labelled seeds. They are useful for regression and robustness testing, but they are not sufficient evidence for a 100% real-world accuracy claim.
